# G2 Share loop (ops)

**Gate:** ≥1 **real human** post per week outside the team, using a Kestrel share card (PNG and/or Discord paste + deep link).

**Status:** **Green** (2026-11-12) — ops posted externally on **Twitter/X** + **Discord** (DOTD share). Keep ≥1 real share/week; re-open if a week passes with zero external posts.

**When:** after G0/G1 are green (copy + spots trusted enough to show outsiders).

## Pass criteria

- At least **one** external share in the last 7 days: Discord (public/LGS), soft Reddit, or WhatsApp/Telegram shop chat with non-team people.
- Post uses in-app share (Trade / DOTD / Radar / Binder) — not a raw screenshot of internal ops.
- Funnel may show `share_copy` / `share_png` in Data Health (persisted), but **event counts alone do not pass G2**.

## Fastest first post (≈5 minutes) — DOTD

1. Open `https://www.kestreltcg.app` signed out (or Pro if DOTD share needs it).
2. Scroll to **Deal of the day** — pick a clear UNDER with spot vs sure fair labeled.
3. Use **Copy deal link** / save PNG (DOTD share buttons).
4. Post in one place you already hang out:
   - LGS Discord / collector Discord, **or**
   - Soft Reddit trade/local thread (verdict in the title, not “Kestrel ad”).
5. Paste template (or use in-app clipboard pack):

```
Kestrel desk call — {card} looks UNDER today.
Spot {spot} vs sure fair {fair} ({edge}).
Desk call — spot vs sure fair band. Not financial advice.
{deal or card URL}
```

6. Attach the PNG if you exported one.
7. Log it: date + channel (Discord/Reddit/WhatsApp) in ops notes or reply here.

## Alternatives (same week)

| If you have… | Use |
| --- | --- |
| A real trade you’re debating | **Trade** → **Copy Discord paste** + PNG → `/trade/s/{id}` |
| Filtered Radar board worth showing | **Radar** → copy share / PNG (`?share=` OG unfurl) |
| A set close to complete | **Binder** → copy set link / PNG (`?set=`) |

## Soft Reddit rules

- Title = verdict (“Even on these 4?” / “UNDER vs fair band — thoughts?”), not brand spam.
- One deep link + PNG; prices refresh live on the link.
- No paid promo flair / affiliate tone.

## Weekly cadence

| Day | Action |
| --- | --- |
| Mon | Pick DOTD or a Trade worth sharing |
| Same day | Post externally + note where |
| Fri | Confirm Data Health saw `share_*` (nice-to-have) + human post still up |

## Fail / redo

- Only team-internal Discord → does **not** count.
- Screenshot without share link → redo with paste pack + URL.
- “AI said buy” framing → rewrite to spot vs sure fair.

## Non-goals

- Ads (Meta / TikTok / X)
- Auto-post bots into public Discords
- Soft Ink branding in user-facing copy (product is **Kestrel**)
